# PHM 实施检查清单 (checklist.md)

## 附录 A：快速验收命令

```bash
# 1. 构建测试
./build.sh -p linux -t debug -T

# 2. 运行测试
cd build && ctest --output-on-failure

# 3. 静态分析
clang-tidy src/*.cpp -- -Iinclude -Ithird_party -std=c++17
cppcheck --enable=all --suppress=missingIncludeSystem src/

# 4. 内存检查（需安装 ASan 支持）
cmake .. -DCMAKE_BUILD_TYPE=Debug -DPHM_BUILD_TESTS=ON
make -j$(nproc)
ASAN_OPTIONS=detect_leaks=1 ./tests/phm_test_config_parser

# 5. 运行时监控
./daemon/phmd -c ../config/phm_se_config.json -v
phm_cli get_global_state
phm_cli list_events --min-severity WARNING

# 6. 检查数据落盘
ls -la /var/log/phmd/data/*/
cat /var/log/phmd/data/*/$(date +%Y-%m-%d)-*.jsonl | head
```
